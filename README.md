## About

I am a self-taught full-stack developer based in Gurgaon, Haryana, India. I build polished web products from scratch, with a focus on clean implementation, rapid prototyping, and practical user experience.

Core stack:

- Next.js, React, TypeScript
- Supabase, PostgreSQL, Drizzle ORM
- HTML, CSS, JavaScript
- Git, GitHub, Vercel
- AI-assisted development with Claude, Gemini, and Codex

## Local Development

Run a local static server from the repository root:

```bash
python -m http.server 8000 --bind 127.0.0.1
```

Then open:

```text
http://127.0.0.1:8000
```
